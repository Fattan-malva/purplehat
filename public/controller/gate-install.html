Install Purplehat

For a faster, native-app feel, install Purplehat to your phone's home screen. Once installed, Purplehat opens as an app (not in the browser).

  1. Tap ⋮ (Chrome menu) in the top-right corner.
  2. Choose Install app / Add to Home screen, then confirm.
  3. Finish the installation. This page automatically continues to the "open app" stage once Chrome signals the installation is done.

Install Purplehat

On iPhone / iPad, install manually via Safari. A regular tab can't open the controller — Purplehat must be opened from the home screen icon.

  1. Tap the Share button (box with an arrow).
  2. Choose Add to Home Screen, then Add.
  3. Open Purplehat from the home screen icon — that's where the controller opens.
